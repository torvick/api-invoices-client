# api-invoices-client

Cliente web para consultar facturas.

## Requisitos

- **Node.js** 18.x o 20.x (LTS recomendado)
- Un **gestor de paquetes**: `npm` (incluido con Node), o `yarn`, o `pnpm`

> Opcional, pero recomendado: **nvm** para manejar versiones de Node  
> - macOS/Linux: https://github.com/nvm-sh/nvm  
> - Windows: https://github.com/coreybutler/nvm-windows

---

## Instalación

Instala dependencias:

```bash
  npm install
```

# Variables:
```bash
  export VITE_API_BASE_URL="http://localhost:3000"
```


# Iniciar servidor de desarrollo
```bash
  npm run dev
```
